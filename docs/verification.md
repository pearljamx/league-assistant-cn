## 手动验收步骤

1. 启动国服客户端与助手，确认当前账号和阶段。
2. 在客户端有正常对局记录时查询本人、同区玩家、下一页和详情；服务失败时确认错误状态与缓存标注。
3. 在设置主动开启自动接受，由用户自行进入队列，确认只接受当前提示；中途关闭开关或离开阶段，确认没有延迟执行。
4. 用户进入选人，换英雄和查看备选席，确认两种胜率口径与英雄一起更新。
5. 用户留出一个符文槽位，预览并应用，确认只新增助手专用页；再次应用复用；满槽时拒绝覆盖其他页。
6. 在海克斯对局中显示三选一并按 F6，确认识别、刷新清除旧结果和穿透点击；识别不可靠时必须为空或提示重试。
