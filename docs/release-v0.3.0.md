# v0.3.0 · PEARLJAM HEX：Akari 式改版（Windows x64 预览版）

「英雄联盟助手」改名 PEARLJAM HEX，主窗口改为紧凑布局，并加入玩家多标签、自动化和工具集。设置与缓存沿用旧目录，升级后保留。

- **界面**：窄侧栏 + 自定义标题栏；总览、推荐、强化排行合并为「英雄数据」页；设置改为分类弹窗；支持系统托盘和 Ctrl+K 召唤师搜索。
- **实时对局**：参考 LeagueAkari 重排为两队上下、每队一行五张卡片，每张显示段位、近期同模式胜率与 KDA、常用英雄、可滚动的近期战绩；标出预组队、遇到过的玩家和连胜连败。身份隐藏的玩家不查询、不推断。
- **战绩**：玩家多标签页，高级筛选，折叠卡片直接显示双方十人，可为玩家写本机备注和标记。
- **小窗**：客户端连接即显示 Mini 窗，选人阶段显示英雄推荐窗；备选席与英雄卡片合并，点头像直接换；可调整大小并记住尺寸和位置。
- **自动化**：自动选择、禁用、抢备选席和自动锁定，全部默认关闭。
- **工具集**：重随、客户端修复、好友与观战、聊天状态与签名，只在点击时执行。
- **海克斯数据**：默认读取公共数据包（aramgg，无需 Key），也可在设置里填个人 Key；三选一显示英雄内相对评级和刷新提示。评级是相对排名，不是获胜概率。

安装版和便携版自带 Python/OCR，无需另装 Node.js 或 Python。下载同页 SHA256SUMS 核对文件，软件未签名。

**尚未实战验收**：自动选择/禁用/锁定、抢备选席、重随、客户端修复、观战、聊天状态、换英雄、符文写入、实时十人页面和多屏 OCR 都还没有在真实客户端或真实对局中完整验证，其中部分写接口仅参考 LeagueAkari。隔离测试通过不代表这些场景已通过。海斗分仍未接入数值，只提供 Hexdata 官方查询入口。自动接受默认关闭，助手不会自行开始匹配。
